# 確認方法と限界

追加テストはNode標準ライブラリだけを使用します。パッケージのインストールは不要です。ソース全体の構文確認と、個別に選択した関数をfake DOM・fake fetch・fake音声・fake保存先で検証します。ゲーム全体のIIFEや実ブラウザ、実データベースへの操作は行いません。

```sh
node tests/static-contract.test.cjs
node tests/isolated-contract.test.cjs
node tests/review-regressions.test.cjs
node tests/ui-integration.test.cjs
node tests/normal8-ranking.test.cjs
```

## 実機で残る確認

- 名前あり・空欄・空白・変更・消去。IME Enterだけで開始しないこと。名前なしでも結果・共有・ランキングを利用できること。
- 各言語で画面と遊び方を確認。言語変更で結果、送信状態、自己ベスト、音設定が変わらないこと。
- 正常終了とリタイア、99匹と残り40匹の加速、既存の配点。実本番へ検証スコアを送らず、承認済みの隔離環境を使うこと。
- ホーム/結果のX共有、確定点・二つのタグ・正式URL、キャンセル復帰、ポップアップ拒否時だけコピー画面が出ること。
- 初回音オン、保存済みオフ/0、最初の操作が消音、共有/画面ロックから戻る、連打や長時間プレイ。音が開始の必須条件にならないこと。
- iPhone Safariの縦横、短い画面、入力キーボード、安全領域、長い名前と30行表示、操作ボタンが隠れないこと。
- 実際のゲーム画面を撮影したサムネイルを準備。代替イラストをゲーム画面の証拠として扱わないこと。

ローカルfakeテストの成功は、実音の適切さ、母語としての翻訳品質、サーバー側の人単位識別、実機や本番配信の確認を意味しません。
