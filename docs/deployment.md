# 公開・実験場連携の適用順

現在の正式URLは確認済みの `https://chameleonjp.codeberg.page/shiwakezaru/` のままです。GitHubリポジトリURLをゲーム公開URLとして扱わず、新URLは配信確認後に確定します。

ランキング詳細は `https://chameleonjp-lab.github.io/chameleonjp_lab/ranking.html?game=shiwakezaru` です。

1. このDraft PRをレビュー。実ゲーム画面サムネイルと実機・実音確認は後続作業として明示。
2. 自動検証・配備を実行できる条件とPages公開元・`github-pages`環境を確認。現PRにworkflowは追加せず、安全性を確認した後続の設定PRで扱います。
3. 別の承認済み設定PRで、PRは検証のみ・mainの成功成果物のみ配信・公開ファイルallowlist・競合防止を導入。本人がマージします。
4. 実際のPages配信URLと配信コミット、ゲーム、言語、音、共有、ランキングを確認。
5. その後、ゲームのcanonical/OG/共有URLと、実験場の既存登録行・カード情報を関連PRで切り替えます。新URL未確認の強制転送は行いません。

実験場側の関連対象は既存 `games` 登録行とランキング・計測導線です。ゲームURL、説明、画像の変更は、実際に使うデータソースを確認し、変更前の控え、期待値付き更新、読み戻し、復元手順を用意してから適用します。リポジトリの予備一覧だけを変えて完了とはしません。

## スコアと計測

現行の通常スコア送信は8列応答です。このPRでは形・名前・点数整合性を検証しますが、同一プレイのサーバー側冪等性や、同じ名前の別人の分離は未解決です。記録の削除、名前からの新しい本人ID生成、既存参加者の作り直しは行いません。

新ゲームの匿名プレイは現在の集計へ含まれません。汎用のイベント書込みを追加するだけでは適切な匿名集計にならないため、関連基盤PRで互換性とプライバシーを確認して対応します。匿名プレイを公開ランキングへ登録して計測を代用しません。

## 配信対象と戻し方

配信対象は `index.html`、`common-ui.js`、`normal-score-ack8.js`、`.nojekyll` の4ファイル。実画面サムネイルを追加した場合はレビュー後に明示的に追加します。テストと開発文書は配信対象外です。

別originへ移るとlocalStorageは自動では移りません。旧URLと旧データを残し、自己ベスト・名前・音量・言語の引継ぎ制約を案内します。デプロイを理由に保存データを一括消去しません。

ロールバックはこのPRへの取り消しPRと、実験場の変更前控えに基づく復元で行います。既存スコアや参加者情報を削除せず、旧公開ページを新URL検証前に停止しません。
