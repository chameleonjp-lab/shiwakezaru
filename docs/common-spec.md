# 仕分けざる：共通仕様の適用

このPRはゲームの移行用候補です。既存READMEを変更せず、既存公開版のルール・ゲーム識別子・保存先を維持します。マージ・配備・データベース変更は含みません。

## 変更内容

- ホームに任意の名前欄を配置。空欄・空白だけでも遊べます。開始時の名前と公開参加可否を固定し、匿名・リタイアの記録は送信しません。
- 日本語、英語、スペイン語、ブラジルポルトガル語、簡体字、フランス語、ドイツ語、韓国語、ロシア語、イタリア語、繁体字、インドネシア語、トルコ語、ベトナム語、タイ語のUI・遊び方・結果・通信状態・共有文を追加。
- ホームと結果に黒地・白文字のX共有ボタンと、ゲーム専用ランキング詳細への導線を配置。Xを開けなかった場合だけコピー用画面を表示します。
- 既存ランキングRPCの取得上限を30件へ拡張。サーバーの順位と同順位を保持し、未取得・不正な順位や最高点は「—」で表示します。表示名による本人判定や順位の推測はしません。
- 既存スコア送信の8列応答について、形・開始時の名前・点数整合性を照合。ゲームと点数方向は既知の要求コンテキストを使います。応答にゲームslugは含まれず、返却されたゲーム識別子の照合ではありません。応答不明・不一致時は結果を保持して再送しません。これは冪等性や人単位の本人確認の証明ではありません。
- 選択、開始、正解、誤分類、逃し、加速、完了、自己ベスト、リタイアに生成SEを追加。初回オン・35%、保存済みオフと音量0を尊重。非表示時停止、遅延再開とノードの後片付けを考慮。
- 44px以上の操作対象、長い文言・名前の折返し、スクロール可能なランキング、IME確定で開始しない入力へ改善。

## 変えていないもの

99匹（25/25/25/24）、正解+10・誤分類−10・逃し−15、基本速度72、残り40匹で1.3倍、リタイア非送信。ゲームslugは `shiwakezaru`、既存送信は `submit_score` の4引数、ランキングは `get_best_score_ranking` のままです。

自己ベスト・リタイア・最後の結果の保存キーは維持します。ゲーム専用名キーが未設定の時だけ旧共有名を読みます。専用名を空欄にすると空欄を維持し、旧共有名を書き換えません。言語と音の設定はゲーム専用キーです。
